# 回答保留与空回答风险排查

## 底线与边界

有可独立通过结构、当前证据 ID 校验的完整内容时，优先保留回答，并将未完成/省略部分明确标为降级。不因一条记录或附加字段失败而丢弃其他有效记录。来源 ID 校验不是语义核验，不能保证每条事实准确。

没有可靠论文依据时，不把模型记忆改写成“论文明确提出”。无 API 响应、无有效记录、无论文数据时不能保证一定有论文答案；应说明原因并允许用户改用明确的通用知识模式。当前不新增自动重试、自动全文回退或付费循环。

## 已修改

- 完整全文/RAG 最终响应：1000–20000 字符的单条论断按1000字符无损拆分，继承原来源ID，不改写文字。拆分仅是显示单元，不将拆出的片段视为新增独立事实。
- 单条 kind/text/heading/引用不合法：仅舍弃该条；保留其他有效条目，Trace记录索引及原因。全部无效时仍明确失败，不能用未经校验的原始输出兜底。
- coverage/caveats/unresolved 附加字段不合法：保留有效正文，丢弃无效覆盖声明，partial；不声称核心问题已答完。
- 超过64条：保留预算内通过校验的前缀，记录省略；不默默截断、不提高模型输出预算。
- 长度截断：此前只恢复已闭合合法记录，现在已闭合长记录也可分段保留；未闭合文本不拼接修补。
- Trace目录/文件写入遭遇OSError：保留已经生成的回答，记录错误类型到进程日志和内存Trace；不能声称该次Trace已经落盘。
- 不对降级答案追加辅助审阅，避免引入额外调用；原始模型事件留作审计。

## 仍可能没有有效论文正文的路径

| 路径 | 具体原因 | 当前处理与边界 |
|---|---|---|
| 最终JSON | invalid_model_json、非对象、缺items | 非长度截断的坏JSON仍停止；未实现任意JSON自动修复 |
| 所有记录无效 | 全部无引用/引用外部论文/空文本/未知kind/异常heading | 明确停止；不降格为“背景”绕过来源校验 |
| 超长异常记录 | 单条超过20000字符，或分段后超过64条且无其他合法记录 | 不展示异常条目；全无效仍停止 |
| 路由前资源条件 | no_paper、无论文/索引、错误页码或检索返回结构 | 没有可用来源；不能制造论文结论 |
| 规划/证据判断 | invalid_plan、invalid_assessment、invalid_action、missing_information_required、foreign_or_unseen_evidence | 当前多数发生在最终生成前，仍停止；未实现跳过规划的自动生成兜底 |
| 本地工具 | Chroma/嵌入/展开组件异常、foreign_source_evidence | 可能没有足够有效证据；现有外围异常处理仍可能不产生正文 |
| 上游服务 | 额度耗尽、认证/权限/限流拒绝、网络超时、model_call_failed | 没有模型答案不能凭空恢复；不自动重试并重复计费 |
| 输入/费用边界 | serialized_input_budget、model_budget_exhausted、model_call_budget、deadline | 保留硬上限；收到响应后发现超时仍可能丢弃，尚未实现迟到结果恢复 |
| 提供商突破输出上限 | provider_output_budget_exceeded | 保持停止及原计费记录；未把超预算原文变成有效正文 |
| HTTP入口 | Token无效、小时次数/Token预算、论文会话不存在、配置不适用 | 拒绝请求，不是模型回答失败；不能绕过权限或预算 |
| 收尾持久化 | 对话存储失败已有保护；Trace磁盘失败本轮补保护 | Token预算结算guard.finish、序列化等外围异常仍需专项故障注入；不能宣称全覆盖 |
| 前端 | 请求断网、服务关闭、解析/页面渲染问题 | 后端有答案也可能显示失败；本轮不代表浏览器端全链路故障测试 |

排查范围：adaptive_research.py、deep_research.py、deep_research_runtime.py、partial_output.py、quality_review.py、app.py。旧/chat及冻结V1适配器不改，不能把新路径修复声称为全仓每个入口均已修复。

## 回放与实验边界

独立工具 replay_answer_validation.py 只读取已保存响应，不调用模型，不覆盖冻结对照。Informer原响应8条，其中1732字符实验条目分成2个显示单元，恢复9个显示单元。回放验证的是“能保留并展示”，不是新的模型质量测评。

原冻结实验的失败仍计入原结果。源码变更后不得继续使用同一manifest付费运行；第二批需重新准备新配置快照，明确批间版本变化。不要删除.started标记或修改hash绕过保护。

## 产品收尾建议（未实施）

默认讲解侧重问题→核心机制→输入输出→少量关键实验，公式只解释作用；用户问局部机制时直接进入该机制，背景最多一句。领域背景与教学类比可以利用通用知识，但必须区别于原论文事实。模型可提出术语/章节检索假设，最终仍以当前PDF核对；不能凭老论文记忆定位出不存在的页码。不要为这一版增加新的多Agent或自评分循环。
