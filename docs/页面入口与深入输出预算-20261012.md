# 页面入口与深入讲解输出预算

根地址 `/` 是原V1的静态index页面，调用旧 `/chat`；`/research` 是新阅读页面，调用 `/research/adaptive`；`/admin/research` 查看管理员Trace。它们共用FastAPI服务、论文库和生成模型配置，但页面和问答流程未合并，也未合并实验分支到main。保留旧入口用于回归和对照。本次不改首页跳转。

启动实验工作树的 `python -m uvicorn app:app --host 127.0.0.1 --port 8010` 后，直接打开 `http://127.0.0.1:8010/research`。旧服务未停止时新进程会因端口占用退出；只重启明确属于本项目的进程。代码与.env修改需重启，没有自动热加载。

用户批准后，将新入口论文全文与RAG深入模式的最终输出上限统一为6400 Token，集中在reading_limits.py。简短与入门上限不变；通用知识、旧V1、资料表抽取2200上限、规划/判断上限、检索/展开次数、证据数量及输入预算不变。6400包含正文及整个JSON元数据，不要求写满，不保证更准，也不保证不会再次达到上限。

新创建的reading pilot manifest记录6400；旧3600实验目录和结果保持原样。脚本在调用前拒绝预算不一致的冻结manifest，不能把旧配置偷偷套到新代码上。已有历史答案回放不受此禁止约束，因为不调用模型。

此前64输出Token探针已经证实一次DeepSeek请求触发上限；本次仅修改配置、离线测试，不调用模型，不据此宣称6400深入回答已经实测完整。

本机禁止外部连接的完整回归：173项通过，无失败/跳过。新增全文与RAG上限一致、两页面调用入口分离、旧冻结预算不能被静默替换三项检查。
