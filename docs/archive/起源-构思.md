流程：

```
PDF

↓

文本

↓

Chunk

↓

Embedding向量

↓

Vector DB

```

例如：

15页。

500 token。

大概：

几十个chunk。

100篇：

可能：

几千个chunk。

向量：

假设：

1536维float。

一个：

约6KB。

10000个：

60MB。

所以：

几十篇甚至几千篇论文：

个人项目完全没压力。
